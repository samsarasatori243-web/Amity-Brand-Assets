# Amity Brand Assets

This is the central repository for approved Amity Power Network brand and website assets.

It is intentionally separate from the Amity website repository and is **not connected to Vercel**. Adding or updating files here will not trigger a website deployment.

## Repository structure

- `logo/` — official Amity logo and approved logo variants
- `homepage/` — approved homepage illustrations and other homepage artwork
- `icons/` — approved icons and small brand graphics
- `approved-designs/` — approved reference images, layouts and design exports

## Asset rules

1. Keep original approved files unchanged. Add revised versions as new, clearly named files rather than silently replacing originals.
2. Use descriptive filenames and include dimensions or version/date where useful.
3. Do not add customer information, private documents, credentials or other confidential material. This repository is public.
4. The website should use the approved original artwork from this repository. Do not substitute approximations or redraw approved illustrations.
5. Before changing the live website, review the exact asset and website implementation together.
